# Visualization

Chem-Predict uses RDKit's MolDraw2D layer for lightweight depictions. The
implementation was checked against RDKit 2026.03.6 documentation.

## SMILES to SVG

```python
from chem_predict.visualization import molecule_svg, save_svg

svg = molecule_svg(
    "CC(=O)Oc1ccccc1C(=O)O",
    atom_indices=True,
    legend="Aspirin",
)

save_svg(svg, "aspirin.svg")
```

## SMILES to PNG

```python
from chem_predict.visualization import molecule_png_bytes, save_png

png = molecule_png_bytes("CCO", legend="Ethanol")
save_png(png, "ethanol.png")
```

## Reaction depiction

For atom-mapped reaction SMILES:

```python
from chem_predict.visualization import reaction_svg, save_svg

reaction = "[CH3:1][Br:2].[OH-:3]>>[CH3:1][OH:3].[Br-:2]"

svg = reaction_svg(reaction)
save_svg(svg, "reaction.svg")
```

Reaction SMARTS can also be rendered:

```python
svg = reaction_svg(
    "[C:1]=[O:2]>>[C:1][O:2]",
    input_format="smarts",
)
```

## Reaction center

Reaction-center detection compares mapped bonds before and after the reaction.
It does not require SynKit.

```python
from chem_predict.visualization import (
    draw_reaction_center,
    find_reaction_center,
)

reaction = "[CH3:1][Br:2].[OH-:3]>>[CH3:1][OH:3].[Br-:2]"

for change in find_reaction_center(reaction):
    print(
        change.atom_map_1,
        change.atom_map_2,
        change.reactant_order,
        "->",
        change.product_order,
    )

view = draw_reaction_center(reaction)

open("reactants.svg", "w").write(view.reactants_svg)
open("products.svg", "w").write(view.products_svg)
open("reaction_center.html", "w").write(view.to_html())
```

For the example above the center contains:

```text
C(1)-Br(2)  1.0 -> 0.0
C(1)-O(3)   0.0 -> 1.0
```

The same atom-map representation can be used to visualize reactions retrieved
from primary databases or generated by a rule engine.

## Relationship to SynKit

The native visualizer handles common mapped-bond changes with only RDKit.

SynKit remains the richer optional backend for ITS graphs, graph rewriting,
mechanistic representations and more complex reaction-graph analysis. The
visualization API should remain independent of a specific graph backend so that
future SynKit views can be added without changing the user-facing functions.
